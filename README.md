# Martínez Home RD — Demo Home

Demo de la página de inicio para **Martínez Home Inmobiliaria** (Lic. Vanessa Martínez, CEO) — Santo Domingo Este, RD.

**Stack:** React 18 + TypeScript + Vite + Framer Motion.

## Secciones
1. **Hero** — título revelado por palabra, buscador con filtros, recorrido virtual, hotspots y contadores animados.
2. **Propiedades destacadas** — slider con filtros (Venta / Alquiler / Proyectos), favoritos y CTA a WhatsApp.
3. **Nuestro enfoque** — servicios: Compra, Venta, Inversión, Asesoría.
4. **Nuestra fundadora** — espacio exclusivo para la CEO.
5. **Síguenos en redes** — reels reales de Instagram (preview al pasar el mouse, lightbox con sonido).
6. **Contacto** — formulario que abre WhatsApp con el mensaje ya redactado.
7. **Footer** — navegación, redes, teléfono y dirección.

> Precios, metrajes y estadísticas son de ejemplo para la demostración.

## Desarrollo
```bash
npm install
npm run dev
npm run build   # salida en dist/
```
